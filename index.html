石塑黏土手工自媒体｜副业项目
Side Project

背景：尝试石塑黏土手工自媒体副业赚取零花钱

挑战：流量低迷、转化率低、作品打磨耗时久

行动：优化封面与作品创意；计划模具批量制作；坚持输出高质量内容

结果：少数笔记流量暴涨，大部分依旧曝光有限

反思：爆款依赖实力与运气；利他、热点内容更利于传播，小众自我表达类内容天然流量受限。

陪拍服务｜副业项目
Side Project

背景：面向同学同龄人提供人像陪拍服务

挑战：不懂定价、成片达不到客户期待

行动：调研同行动态调价；拍摄前对齐风格，陌生风格提前学习，现场实时沟通调整

结果：积累客户与复约，几乎无不满意反馈

反思：放下专业完美主义，普通客户核心需求是把人拍好看；服务的沟通预期管理与技术同等重要。

01｜鲜花摆摊副业

个人副业｜角色：独立执行者

Context 背景

大学生副业尝试；希望小成本实践商业，接受试错，明白学生阶段试错成本较低。

Problem 问题

点位选择、货源与鲜花损耗风险；缺乏售卖经验；备货与销量难以预估。

Role 我的角色

独立完成点位调研、货源比对、成本测算、备货、现场售卖、事后复盘全部流程。

Process 过程

  • 前期：线上搜集点位再实地踩点；核算进货、损耗成本，设置售价；
  • 第一轮执行：备货过多，鲜花脱水挤压，出现亏损；
  • 迭代：减少备货，优化鲜花保水、搬运方式，降低滞销损耗。

Outcome 产出结果

有账面亏损，但完成完整小商业闭环；验证小规模试错的重要性，不盲目扩大投入。

【替换：摆摊实拍、成本笔记照片】

Reflection 复盘反思

大学做副业不必追求盈利作为唯一标准；提前预判损耗风险；初期规模要克制；失败也是宝贵的学习成本。

02｜时光信封｜跨社团联合活动

社团活动｜角色：DIY手工社社长

Context 背景

收到文学社合作邀约，两个社团需要开展一场跨社团联合活动。

Problem 问题

手工和文学如何融合；如何增加活动趣味性；两个社团之间如何划分分工。

Role 我的角色

我方社团负责人：负责创意构思、我方人员安排、折纸教学物料准备，跨社团沟通对齐目标。

Process 过程

  • 构思“时光信封”创意：折纸信封+手写信件，打通手工实操和文学表达；
  • 和合作社团对齐分工：我方负责折纸教学，文学社维持写信秩序与一年后信件配送；
  • 风险预案：提前打印大量图片教程，应对现场人数超出预估。

Outcome 产出结果

活动火爆，原定纸张耗尽，临时使用A4打印纸补给；依靠教程分流，现场秩序维持良好，参与者反馈热烈。

【替换：活动现场、信封成品照片】

Reflection 复盘反思

好活动同时需要创意构思和落地执行；多方协作需要对齐目标、明确职责节点；要提前预判物料、人流等风险，分歧主动协商达成共赢。
